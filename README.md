## 🔎🤔Sherlock Holmes - File Edition
Mini python project:  File Investigator

**📌Practising some Python fundamentals**
### *Features*
- Counts files in a folder by type
- Detects large files (>10 MB)
- Supports common text, image, video, audio, and compressed/archive formats

 ### How to run
 - Requires: Python 3.x, os module
 #### Running the program
 1. Clone the repository
    - (bash)
    ```
    git clone https://github.com/katrina-nne/sherlockHolmes-fileEdition.git
    ```
 2. Go to project folder
    ```
    cd sherlockHolmes-fileEdition
    ```
 3. Run the program
    ```
    python FileInvestigator.py
    ```
 4. Enter the path to the folder to be investigated when prompted:
    - eg. "C:\Users\Katrina\Natis"
